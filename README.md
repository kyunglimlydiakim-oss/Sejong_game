# 그(?)와 함께 세종대왕

초성을 보고 그 초성의 낱말을 대는 대결 게임이다. 세종대왕은 초성만 내린다. 낱말은 그(?)가 먼저 대고, 그다음 내가 번갈아 댄다.

- 내 차례에 30초 안에 맞는 낱말을 못 대면 목숨(♥)이 하나 준다. 셋을 다 잃으면 게임이 끝난다.
- 한 판은 열 차례(그(?) 5, 나 5)다. 열 차례를 넘기면 새 초성으로 다음 판이 시작된다.
- 글자 수는 판마다 바뀐다. 1판 두 글자, 2판 세 글자, 3판 네 글자, 그다음 다시 두 글자로 돌아간다.
- 틀린 낱말은 목숨을 깎지 않는다. 남은 시간 안에 다시 대면 된다. 사전을 조회하는 동안에는 시계가 멈춘다.
- 점수: 맞힐 때마다 10점에 남은 초를 더한다. 한 판을 마치면 30점, 그(?)가 막히면 20점을 더 받는다. 그(?)도 같은 방식으로 점수를 쌓는다.
- 그(?)는 가끔 막힌다. 1판에 4%로 시작해 판마다 3%포인트씩 오르고, 25%에서 멈춘다(`stumpChance`).

## 화면

- `assets/bg.webp`: 광화문광장 밤 배경. 그림 속 말풍선에 초성과 대왕의 말이, 아래 입력판에 내 답이 들어간다.
- `assets/geu.webp`: 그(?)의 스프라이트. 원본의 마젠타 배경을 지우고 260×230 칸 9열 3줄로 다시 묶었다.
  1줄 대기(9컷), 2줄 만세(9컷), 3줄 속상(8컷)이다. 평소엔 대기 동작을 한다. 내가 시간을 넘기거나 게임이 끝나면 만세를, 그(?)가 막히거나 내가 한 판을 버티면 속상 동작을 한다.

## 소리(`sound.js`)

소리 파일 없이 Web Audio API로 실시간 합성한다. 전역 `SoundManager`로 부른다. 타입은 `sound.d.ts`에 있다.

```js
SoundManager.play("coin");               // 띠링~  사각파 B5→E6 두 음
SoundManager.play("click");              // 톡-    삼각파 1.5kHz→700Hz, 0.045초
SoundManager.play("levelup");            // 도-미-솔-도 사각파 아르페지오 + 옥타브 아래 삼각파
SoundManager.play("gameover");           // 톱니파 440→55Hz 미끄럼 + 반음씩 내려가는 사각파 + 낮은 쿵
SoundManager.play("hit", { volume: .4 }); // 화이트 노이즈(필터 5kHz→200Hz) + 사각파 160→45Hz
SoundManager.bgm.start();                // 아리랑 후렴, 3/4박, 4분음표 104
SoundManager.toggleMute();               // 상태는 브라우저에 기억된다
```

- 브라우저 자동 재생 정책 때문에 AudioContext는 첫 클릭·터치·키 입력 때 만든다. 그 전의 `play()`는 무시되고,
  `bgm.start()`는 첫 상호작용 뒤로 미뤄진다. 탭을 떠나면 소리를 멈췄다가 돌아오면 이어 간다.
- 게임에서는 정답·그(?)가 막힘 → coin, 버튼 → click, 판 승리 → levelup, 게임 오버 → gameover,
  시간 초과 → hit, 틀린 답 → 작은 hit를 낸다.
- 배경음악 선율은 `sound.js`의 `ARIRANG`에 계이름 숫자(도=1)로 적었다. `5:3`은 솔을 8분음표 3개 길이로,
  `1'`은 한 옥타브 위 도를 뜻한다. 악보와 대조하지 못한 채 옮긴 것이라, 귀에 다르게 들리면 이 줄만 고치면 된다.
- `SoundManager.renderOffline("coin")`(또는 `"bgm"`)은 소리를 오프라인으로 렌더링해 AudioBuffer로 돌려준다.

## 공개 배포(Vercel) — 누구나 링크로 접속

`api/` 폴더의 서버리스 함수가 표준국어대사전 API를 대신 부른다. 인증키는 Vercel 환경 변수에만 두므로 방문자에게 드러나지 않는다.

1. https://vercel.com 에 GitHub 계정으로 가입한다.
2. **Add New → Project**에서 이 저장소(`Sejong_game`)를 고르고 **Import**한다.
3. Root Directory는 그대로(`./`) 둔다. Framework Preset은 `Other`다(`vercel.json`에 적어 두었다).
4. **Environment Variables**에 `STDICT_API_KEY` = 발급받은 인증키를 넣는다.
5. **Deploy**를 누른다. `https://프로젝트이름.vercel.app` 주소가 생긴다.

- 함수는 서울 지역(`icn1`)에서 돌도록 `vercel.json`에 적어 두었다.
- 같은 낱말 검색은 하루 동안 Vercel CDN에 저장해 일일 호출 한도를 아낀다.
- `main` 브랜치에 올리면 정식 주소가 자동으로 다시 배포된다.

## 내 컴퓨터에서 실행

1. 저장소 폴더에 `api_key.txt` 파일을 만들고 표준국어대사전 인증키(16진수 32자리)만 한 줄로 적는다.
   이 파일은 `.gitignore`에 들어 있어 저장소에 올라가지 않는다.
2. 그 폴더에서 `python3 server.py`(윈도우는 `python server.py`)를 실행한다.
3. 브라우저에서 http://localhost:8000 을 연다. 오른쪽 위에 '판정 표준국어대사전 연동'이 뜨면 연결된 것이다.

인증키 없이 실행하면 내장 자료(표준국어대사전 내려받기 자료)로 판정한다. 파이썬 3.8 이상이면 되고, 외부 라이브러리는 필요 없다.

## 판정 방식

- 연동 모드: 중계 서버가 표준국어대사전 오픈 API(`search.do`)를 대신 부른다. 조건은 고급 검색, 정확히 일치,
  어휘(구·속담 제외), 입력한 낱말과 같은 음절 수다. 내 컴퓨터에서는 `server.py`, 공개 배포에서는 `api/` 함수가 이 일을 한다. 표제어가 있으면 정답으로 치고, 첫 뜻풀이를 기록에 보여 준다.
  표준국어대사전 API는 인증키가 필요하고 브라우저에서 바로 부르면 CORS에 막혀서 중계 서버를 둔다.
- 내장 자료(`words.js`, `tools/build_words.py`로 생성):
  - 판정용: 「표준국어대사전」 전체 내려받기(2026. 6. 5. 생성) 중 두~네 글자 '단어' 표제어 249,962개.
    서버 연결이 없거나 끊기면 이것으로 판정한다. 실시간 검색에 없는 낱말도 이 자료에 있으면 인정한다.
  - 그(?)의 낱말: 「한국어기초사전」(2026. 6. 19. 생성) 명사. 네 글자는 부사와, 기초사전 초·중급 두 글자 명사 둘을
    이은 표준국어대사전 명사(예: 고등학교)를 더했다. 그(?)가 한 판을 버틸 만큼 낱말이 있는 초성만 낸다
    (두 글자 10개 이상 165개, 세 글자 10개 이상 318개, 네 글자 6개 이상 56개).
  - 두 사전 자료는 국립국어원이 CC BY-SA 2.0 KR로 배포한다. `words.js`도 같은 조건을 따른다.
