# 그(?)와 함께 세종대왕

초성 두 개를 보고 두 글자 낱말을 대는 대결 게임이다. 세종대왕은 초성만 내린다. 낱말은 그(?)가 먼저 대고, 그다음 내가 번갈아 댄다.

- 내 차례에 10초 안에 맞는 낱말을 못 대면 목숨(♥)이 하나 준다. 셋을 다 잃으면 게임이 끝난다.
- 한 판은 열 차례(그(?) 5, 나 5)다. 열 차례를 넘기면 새 초성으로 다음 판이 시작된다.
- 틀린 낱말은 목숨을 깎지 않는다. 남은 시간 안에 다시 대면 된다. 사전을 조회하는 동안에는 시계가 멈춘다.
- 점수: 맞힐 때마다 10점에 남은 초를 더한다. 한 판을 마치면 30점, 그(?)가 막히면 20점을 더 받는다. 그(?)도 같은 방식으로 점수를 쌓는다.
- 그(?)는 가끔 막힌다. 1판에 4%로 시작해 판마다 3%포인트씩 오르고, 25%에서 멈춘다(`stumpChance`).

## 화면

- `assets/bg.webp`: 광화문광장 밤 배경. 그림 속 말풍선에 초성과 대왕의 말이, 아래 입력판에 내 답이 들어간다.
- `assets/geu.webp`: 그(?)의 스프라이트. 원본의 마젠타 배경을 지우고 260×230 칸 9열 3줄로 다시 묶었다.
  1줄 대기(9컷), 2줄 만세(9컷), 3줄 속상(8컷)이다. 평소엔 대기 동작을 한다. 내가 시간을 넘기거나 게임이 끝나면 만세를, 그(?)가 막히거나 내가 한 판을 버티면 속상 동작을 한다.

## 실행

1. 이 폴더에 `api_key.txt` 파일을 만들고 표준국어대사전 인증키(16진수 32자리)만 한 줄로 적는다.
   이 파일은 `.gitignore`에 들어 있어 저장소에 올라가지 않는다.
2. 이 폴더에서 `python3 server.py`(윈도우는 `python server.py`)를 실행한다.
3. 브라우저에서 http://localhost:8000 을 연다. 오른쪽 위에 '판정 표준국어대사전 연동'이 뜨면 연결된 것이다.

환경 변수로 넘겨도 된다: `STDICT_API_KEY=발급받은키 python3 server.py`

인증키 없이 실행하면 오프라인 모드로 돌아간다. 이때는 내장 단어 목록으로 판정한다.
파이썬 3.8 이상이면 되고, 외부 라이브러리는 필요 없다.

## 판정 방식

- 연동 모드: `server.py`가 표준국어대사전 오픈 API(`search.do`)를 대신 부른다. 조건은 고급 검색, 정확히 일치,
  어휘(구·속담 제외), 두 음절이다. 표제어가 있으면 정답으로 치고, 첫 뜻풀이를 기록에 보여 준다.
  표준국어대사전 API는 인증키가 필요하고 브라우저에서 바로 부르면 CORS에 막혀서 중계 서버를 둔다.
- 그(?)가 내는 낱말과 오프라인 판정에는 국립국어원 「한국어 학습용 어휘 목록」(2003, 5,965개)을 쓴다.
  그중 두 글자 단어 2,687개만 `words.js`에 담았다. 출제하는 초성 쌍은 이 목록에 낱말이 12개 이상 있는 79쌍이다.
  이 목록은 공공누리 제1유형이며 동음이의어 구분은 표준국어대사전을 따른다.
